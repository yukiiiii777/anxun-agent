## 分工原则

**按交付物分，不按环节分。**

每个人从头到尾负责一类东西，交接点只有三个，责任清楚。

最怕的分法是「你做模型我做 PPT 最后拼起来」——中间没有交接标准，最后一定对不上。

详见 [`../docs/07-分工与计划.md`](../docs/07-分工与计划.md)。

---

## 三个交接点

| 交接 | 从 → 到 | 对方拿到后必须能做什么 |
|---|---|---|
| 数据 → 模型 | 全队 → 队长 | 执行一条命令就能开训 |
| 模型指标 → PPT | 队长 → 队友 B | 四个数字 + 两张图，直接填进第 11 页 |
| Agent 链接 → 视频 | 队友 A → 队长 | 打开就能演示完整链路 |

## 站会约定

每天固定时间，10 分钟，每人三句话：

1. 昨天交付了什么（对着任务编号说）
2. 今天交付什么（编号 + 截止时间）
3. 卡在哪

**卡超过 1 小时就说话。** 三个人 10 天，没有硬扛的余量。
