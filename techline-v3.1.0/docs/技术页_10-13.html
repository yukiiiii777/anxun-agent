为什么放弃火焰检测，改做安全帽

同一个赛题下我们比较了三个方向。放弃不是做不出来，是做不稳。
火灾 / 烟雾检测PPE 穿戴检测（选定）
任务本质语义判断 —— 「像不像火」存在性判断 —— 「头上有没有」
主要干扰源蒸汽、粉尘反光、红色物料、焊接弧光遮挡、光照（都可控）
精度天花板换一个厂区就掉一大截类别稳定，可做高
演示风险灯光一变就翻车，录屏不可复现同一条素材录几遍结果一致
误报代价高（一次误报就是一次停产疏散）低（补一顶帽子，成本可忽略）
能否闭环到工单难，火情不是「限期整改」的事能，责任人 / 时限 / 复查都成立
在工业场景里，宁可做一个可靠的小任务，也不做一个不可靠的大任务。
我们要证明的不是模型能识多少类，而是识别结果能不能变成一条有人负责的工单。

创新点与跨学科视角

两个创新点，各配一句能被记住的话。
创新点 01

感知闭环：让 Agent 有眼睛

多数 Agent 作品停在「对话」。我们把摄像头接进决策链：看得见（单模型五类：人体与装备同一次前向输出）→ 判得准（四态判定 + 正反证据融合：有帽框算戴、裸头框算没戴、两者都有转人工）→ 落得下（工单 + 状态机）。 并且为实时视频专门做了三级触发——抽帧 / 帧差 / 无人门控，前向从 240 降到 39（省 84%）。 帧差阈值踩过坑：v1.2 为压机位抖动把它提到 10.0，而走动帧差中位数是 9.88—— 一半走动帧被当成静止跳过；v2.1.0 降回 3.0（跳过率 9.6%）。 现场的浪费从来不是「模型慢」，而是「算了不需要算的帧」，但不能连该算的也一起省。

「看得见 → 判得准 → 落得下」
创新点 02

定级有据：等级不由大模型拍脑袋

同样的「没戴帽子」，在高处作业平台是 R=16 立即停工的红色风险，在原料库装卸区是 R=3 加强关注的蓝色。 定级走 R = L × S 查表 + 法规条款映射，纯确定性计算，同一输入连跑三次结果一致，敢让评委当场重算。

「告警是一条通知，工单是一个责任」
