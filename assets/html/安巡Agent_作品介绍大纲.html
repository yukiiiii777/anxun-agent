作品介绍大纲 · 用于 PPT、答辩、申报材料、向老师汇报

安巡 Agent
讲这件作品时，该讲清楚哪七件事

面向中小制造企业的厂区安全巡检多智能体系统
一句话版本：把「工人有没有戴安全帽」这件天天检查、天天失守的事，做成一条从摄像头画面到整改工单的完整闭环——不只报警，还负责派人、定时限、跟复查、留证据。
讲这件作品的总原则：不要从「人工智能很火」讲起，要从一个具体的、听的人能立刻想象的场景讲起。评委一天看几十个作品，记住的永远是那个有画面感的。

一、问题：为什么这件事值得做

这一节只讲矛盾，不讲技术。目标是让听的人点头：「对，这确实是个事。」

1.1法规是刚性的，执行是虚的
《安全生产法》要求提供符合标准的防护用品并监督佩戴。但中小厂实际靠班组长目视、靠检查前突击提醒。
1.2一个人管不住几个车间
安全员往往兼管环保、职业健康、消防，无法全天候覆盖。工人见到检查的人就戴，人一走就摘。
1.3发现了，但没人管到底
纸质记录事后补填；隐患整改没有责任人、没有时限、没有复查。同一批问题反复出现。
1.4现有的视觉方案只做到一半
装了摄像头、上了 AI 识别，但系统只负责「报警」。报警之后的派单、整改、复查，全在系统之外靠人。
一句话收束这一节：摄像头能看见，但没有人管到底。这是整件作品存在的唯一理由，其他所有内容都是为它服务的。

二、方案：我做的是什么

这一节讲形态和链路，仍然不深入技术。

2.1 形态：五个角色，各管一段

Agent干什么一句话价值
① 巡检规划定今天去哪些区域、重点看什么不是平均用力，历史高发区加密
② 视觉感知看画面，判断有没有戴这是作品的「眼睛」
③ 隐患研判判断严重程度、要不要停工等级有算的依据，不是拍脑袋
④ 工单闭环派活、定时限、跟复查这是作品的「手」
⑤ 合规问答回答依据是哪一条法规每条结论都能追到出处

2.2 一句话讲清链路

规划去哪儿看 → 看见有没有戴 → 判断有多严重 → 派人多久改完 → 查有没有改

和现有方案的本质区别，就一句话：别人做的是「告警」，我做的是「工单」。
告警是一条通知，工单是一个责任。这句话是整个作品最值得记住的定义。

三、技术：四个关键决策

这一节是作品的技术含量所在。不要罗列用了什么框架，要讲「为什么这么选」。

3.1决策一：为什么不做火灾检测，改做 PPE
火焰检测是语义判断——「这像不像火」，蒸汽、粉尘反光、红色物料都能骗过模型，工业现场误报高到不可用。
PPE 是存在性判断——「头上有没有安全帽」，有明确答案。
结论：在工业场景里，宁可做一个可靠的小任务，也不做一个不可靠的大任务。
3.2决策二：判定逻辑和检测模型解耦
模型只产框，规则引擎做判断。好处：换模型不用改业务、换平台不用改模型、模型没训好也能先把链路演示出来。
3.3决策三：计算交给公式，语言交给模型
大模型算乘法不可靠。风险值 R = L × S 必须走确定性计算，同一输入永远同一输出。
说服力在于：评委当场让你重算，结果一样。
3.4决策四：宁可漏报，也不误报
置信度三档（≥0.6 定论 / 0.4–0.6 转人工 / <0.4 丢弃）、连续 3 帧一致才定论、过小目标直接判「无法判定」。
理由：一次误报会让人直接关掉整个告警系统，这个损失比漏报大得多。

五、价值：谁受益，怎么算

对象价值可量化方式
中小制造企业补上安全员盯不过来的缺口巡检覆盖率、真实合规率的提升
安全管理人员从「找问题」变成「管整改」隐患闭环时长、逾期未整改数
被检查方检查有据可查，不用事后补记录证据留存率、追溯时间
行业把「监控」推向「管理」从告警数量到整改完成率的转变
讲价值时不要只讲省钱。这类作品的加分点在「管理闭环」而不是「节省人力成本」——后者容易被追问「你算过 ROI 吗」，前者可以讲流程改造，更站得住。

六、边界：我做不到什么

这一节不是自曝其短，是证明你清醒。主动讲局限的队伍，评委反而更信。

6.1技术边界
只覆盖正面与侧面视角；未做跨镜头人员重识别，同一人换镜头会重复计数；阈值依赖像素尺度，换相机需重新标定。
6.2责任边界
定位为辅助管理工具，不替代安全管理人员的判断，不作为事故定责依据。
6.3伦理边界
只识别防护装备状态，不采集人脸、不推断身份；数据聚合到班组层面用于培训改进，不做个人排名、不做处罚依据。
6.4下一步
扩展隐患类型（通道占用、动火作业监护）；接入企业已有摄像头免改造；沉淀行业级隐患知识库。

七、不同场合的讲法

一句话（10 秒，用于自我介绍、群发介绍）
安巡 Agent 是一个厂区安全巡检智能体，它不只识别工人有没有戴安全帽，还会自动生成整改工单、派给责任人、定时限、跟复查。
30 秒版（用于老师问「你在做什么比赛作品」）
厂区安全检查有个老问题：法规要求天天查，但一个安全员管不了几个车间，而且检查的人一走工人就摘帽子。现有的 AI 摄像头只负责报警，报警之后没人管。我们做的系统在这条链路上补了后半段——识别出违规之后，自动判断严重程度、生成整改工单、指派责任人、设定时限，到期没改会自动升级。技术上最关键的一点是，我们不做火焰检测，因为那是语义判断，误报率在工业现场根本没法用；我们做的是安全帽这种存在性判断，有明确答案。
6 分钟版（答辩视频结构）
0:00–0:45　问题：法规刚性 vs 执行虚化，用真实场景切入
0:45–1:30　方案：五个 Agent 各管一段，一句话讲清链路
1:30–2:30　数据与知识库：权威性 + 现场适配
