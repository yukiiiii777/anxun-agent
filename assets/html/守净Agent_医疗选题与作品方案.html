一、为什么是院感，而不是问诊

走医疗赛道最大的陷阱是这个：大多数人会做「智能问诊 / 健康咨询」Agent——因为不需要任何数据、一晚上就能搭出来、讲起来还显得专业。结果就是评委一天要看几十个几乎一样的对话机器人。

院感防控（IPC，Infection Prevention and Control）是另一种打法。它属于官方定义里的「医疗流程智能化升级」，但它考核的对象是医院的管理动作，不是病人的诊断结论。这一区别带来三个直接好处：

不碰诊断红线
不输出任何医疗建议，不涉及 AI 辅助诊断的伦理争议和医疗器械资质问题。答辩时这是优势不是短板。
数据可以自采
手卫生动作、防护穿戴、医废投放都能在实训室模拟拍摄，不需要医院病历或影像数据。
能力直接复用
你的 YOLO 检测 + 姿态估计能力是主干，不是点缀。技术章节能写实、有指标。
一句话定位：把「手卫生依从性、防护穿戴、医疗废物分类」这三件靠人盯、靠填表、靠抽查的事，变成一条由多个 Agent 协同完成、有视觉模型做眼睛、有院感规范做依据、有科室整改做闭环的自动化流程。

二、痛点为什么成立

痛点具体表现可论证的抓手
手卫生依从性虚高 国际通行做法是「直接观察法」由院感专员现场盯人记录，但这是霍桑效应最典型的场景——被盯的时候人人洗手，专员一走就恢复原样。样本量还受人力限制。 霍桑效应是有文献支撑的方法学缺陷，在这里主动指出行业方法的局限，是评委最认的「问题理解深度」
监测频次不足 院感科通常只有 1–3 人，要覆盖全院几十个科室，只能按月抽查重点科室 覆盖率是可量化指标：人工抽查 vs 全天候覆盖
医废分类错误 感染性、损伤性废物混投是卫生监督执法检查的高频扣分项，且存在职业暴露风险 分类错误率是硬指标，且有明确法规依据
预警滞后 院感聚集性事件往往在病例数上升后才被发现，缺少过程指标的早期信号 引入 SPC 统计过程控制，从「事后统计」转到「过程预警」
引用的规范必须逐条核对原文，这是答辩生死线。本方案涉及的可引用文件方向（需你自行核实版本与条款号）：《医院感染管理办法》、《医务人员手卫生规范》WS/T 313、《医疗废物管理条例》、《医院消毒卫生标准》GB 15982。手卫生指征可对标 WHO「手卫生五个时刻」——接触患者前、清洁/无菌操作前、体液暴露风险后、接触患者后、接触患者周围环境后。这五条是国际通用框架，讲出来评委一听就知道你查过资料。条款号、发布年份、现行有效性，提交前务必到国家卫健委或标准全文数据库核对。

三、系统架构：五个 Agent

不要做成一个大 Agent 塞满提示词，评委会觉得在套模板。按院感管理流程拆角色，每个 Agent 职责单一、输入输出明确。

① 监测规划 Agent→ ② 视觉感知 Agent→ ③ 风险研判 Agent→ ④ 整改闭环 Agent→ ⑤ 规范问答 Agent
Agent职责关键设计（答辩讲这个）
① 监测规划 按科室风险等级（ICU、手术室、血透室、新生儿科为高危）和历史依从性数据，动态分配监测点位与频次 不是平均用力，是风险加权——有限算力优先投给高危科室
② 视觉感知 识别手卫生动作关键节点、口罩/手套/隔离衣穿戴状态、医废投放类别 这是你的护城河。模型作为 Agent 的原生 tool 接入，不是外挂
③ 风险研判 聚合到科室层面计算依从率、做趋势判断、识别异常波动并给风险等级 用 SPC 控制图判断「是否异常」，而不是拍一个固定阈值
④ 整改闭环 低依从科室生成培训工单、指派院感监控员、限期复查、追踪改善曲线 PDCA 闭环，对应管理学语言，评委听得懂
⑤ 规范问答 RAG 检索院感规范，给出整改依据条款原文 每条建议「有出处」，这是可信度来源
答辩杀手锏：评委问「这和装个摄像头人工看有什么区别」，答案是——人工看的时候人会自动表现好，机器看的时候不会。我的系统测的是真实依从性，不是被观察时的依从性。这一句直接把你和「监控方案」区分开。

3.1 技术实现路线：为什么这条比训练检测模型容易

关键判断：手卫生与穿戴识别，不需要从零训练一个高精度检测器。不要用「训练 YOLO 检测火焰」的思路来做这件事，那是错配。
层级做法为什么可行
第一层
现成能力		调用开源人体姿态估计模型取关键点（手、肘、肩、头）人体关键点检测是成熟任务，预训练模型泛化好，不需要自己标注训练
第二层
规则判定		由关键点几何关系 + 时序判断：手是否进入洗手台区域、停留时长是否达标、是否经过规定动作节点这是一个几何与时序问题，规则可写，不依赖语义理解的准确率
第三层
时序聚合		连续多帧一致才判定为一次有效手卫生，单帧异常丢弃把单帧抖动的影响压掉，鲁棒性远高于逐帧判定
第四层
可选微调		用少量自采数据微调一个动作分类器，提升特定场景表现是锦上添花，不是成败前提。时间不够可以不做

为什么这比火灾检测简单？火灾检测要回答的是「这是不是火」——语义边界模糊，蒸汽、粉尘反光、夕阳都能骗过模型，所以精度难提。而手卫生判定回答的是「手有没有移动到规定位置、有没有持续够时长」——这是几何和时序问题，有明确答案，规则写得出来。你之前在火焰检测上吃过的精度苦，在这个场景里大部分不会出现。

降级策略（写进 PPT，答辩加分）：如果姿态估计在真实病房光照下不够稳定，退一档做「洗手台区域人员停留时长 + 动作幅度」的粗粒度判定，仍然能产出有意义的依从性指标。分级降级意味着这个作品在任何技术条件下都能交付，而不是全有或全无。评委很认这种工程成熟度。

四、数据与知识库：决定分数上限的一章

官方在这一章给了 2–4 页，并明确要求说明数据渠道的「权威性与时效性」。医疗领域尤其看重这个，必须写实、写出处。

4.1 数据来源

序来源类型怎么用
1实训室模拟采集（主力）一手实拍按 WHO 五个时刻 × 七步洗手法设计动作脚本，多角度、多光照、多人拍摄。主要用途是标定规则阈值（停留时长、位置判定、动作时序），不是训练检测器——数据量需求低一个数量级
2开源姿态估计预训练模型成熟开源模型提供人体关键点检测能力，开箱可用，不需要自建训练集 具体选用哪个模型需核实并在 PPT 注明
3院感规范与标准文本政府规范性文件构成知识库，条款可溯源
4公开院感监测统计年报行业权威统计做基线对比，论证问题的普遍性 需核实可获取性与引用口径
诚实原则：第 2、4 项如果最后拿不到，就不要写。编一个查不到出处的数据集名字，通讯评审阶段没人管，进了区域赛现场答辩被问一句就崩。宁可只写「自采 + 规范文本」两个渠道——官方要求是 2–3 个，两个合规。

4.2 知识库的四个层次

  • 法规层：《医院感染管理办法》《医疗废物管理条例》及地方卫生监督要求
  • 标准层：WS/T 313 手卫生规范、GB 15982 消毒卫生标准、隔离技术规范
  • 操作层：七步洗手法、防护用品穿脱顺序（PPE donning/doffing 顺序本身就是考核点）
  • 经验层：历史整改案例、常见违规类型清单

4.3 预处理流程

动作脚本设计→ 多角度拍摄→ 抽帧去重→ 关键点/框标注→ 数据增强→ 训练与验证

文本侧走：规范 PDF 解析 → 按条款切分（不是按字数切）→ 向量化 → 检索。按条款切分能保证检索结果永远是完整条款，不会断章取义——这个细节写进 PPT，是「预处理专业性」的直接体现。

五、创新性：官方标注的「额外加分」怎么填

创新点一：消除观察者效应
传统直接观察法测的是「被观察时的依从性」，本身有系统性偏差。非接触式连续监测测得的是真实行为分布。这不是技术炫技，是方法学层面的改进——主动指出行业方法的缺陷，比多做一个功能更能体现问题理解深度。
创新点二：SPC 过程预警
院感监测惯常是事后统计月度感染率。本作品把统计过程控制图引入依从性监测，在指标出现异常趋势（连续多点同侧、超出控制限）时提前预警，把「事后统计」变成「过程干预」。

独特视角（跨学科）：公共卫生的方法学（依从性测量）× 计算机视觉的检测能力 × 管理学的 PDCA 闭环。三层学科语言在一个系统里对齐——正好对应大赛「横向复合型人才」的选拔取向。这一段要写成研究贡献的口吻，不要写成宣传语。

六、应用结果呈现：把「能跑」变成「可验证」

10.2 评委可能问的问题

  • 「这不就是监控员工吗？」→ 关键在设计原则：数据只聚合到科室层面用于培训改进，不做个人排名、不做处罚依据；只存动作类别与计数，不存人脸。这既是伦理立场也是落地前提。
  • 「动作识别准不准？漏判怎么办？」→ 报实测指标，讲清楚只做高置信度判定，低置信转人工复核，宁可漏报不误报——因为误判会直接摧毁医护的信任。
  • 「这和现成的院感监测系统有什么区别？」→ 现有系统多是人工录入 + 事后统计；本作品是过程数据的自动采集 + 实时预警 + 闭环整改。
  • 「医院凭什么买？」→ 等级医院评审和院感质控考核有硬性指标，依从性数据是必查项；替代的是人工观察的人力成本。
  • 「数据隐私怎么合规？」→ 视频边缘侧处理不出院，只上传结构化结论；不采集人脸与患者身份信息，符合最小必要原则。
  • 「为什么选医疗而不是制造或教育？」→ 这个问题要准备。答案不要讲「医疗更有价值」，讲「院感防控的数据可以通过模拟采集获得，而诊断类数据拿不到，所以这是我能做扎实的那一块」——诚实且专业。
