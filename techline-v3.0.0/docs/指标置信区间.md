## 三、mAP 为什么没有区间

自助法（bootstrap）需要**逐图 AP**，即每张图单独算一次匹配结果。
当前 `data/metrics_*.json` 只存了逐类 AP 和 PR 曲线上的点，没有逐图结果，
用现有数据算出来的「区间」是假区间。要么改 `evaluate_real.py` 落逐图结果，要么不给区间——
这次选后者，并在 PPT 上只报点估计 + 说明测试集规模。
