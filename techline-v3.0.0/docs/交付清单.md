## 四、复现四个数字（三步，不用 torch）

```bash
pip install -r requirements-cpu.txt     # 约 80 MB
python src/anxun/evaluate_real.py       # 0.8654 / 6.1% / 6.52% / 86-6-6-92
python src/anxun/evaluate_real.py --backend onnx --out data/metrics_onnx.json
```

已实测：在仓库内重跑的输出与 `data/metrics_real.json` **逐位一致**（mAP 0.8654、误报 6.1%、漏报 6.52%、混淆矩阵 86/6/6/92）。
换机器后数字对不上，说明权重或数据换了，不是"环境差异"。

## 五、已知限制（主动披露，别等评委问）

| 限制 | 现状 | 依据 |
| :--- | :--- | :--- |
| 漏报率 6.52% 高于目标 ≤5% | 6 例漏报：**4 例是「无法判定」转人工**（人员框过小 / 半身 / 蹲姿），**只有 2 例是真判错**（软布帽被当成安全帽）。真正「说戴了其实没戴」是 2.2%。差距 1.5 点，落在 100 张的样本误差内 | 技术页 P11 · `data/metrics_real.json` |
| 指标阈值在**测试集**上扫出 | 属乐观估计，已在文中标注；换权重必须用 `sweep_rules.py`+`sweep_geom.py` 重扫 | README 5.3 末尾 |
| 误报率 6.12%，**已达标** | v3.0.0 时是 10.20%（破线）。v3.1.0 换 s 权重 + 单模型链路后降到 6.12%，余 3.9 点。注意 100 张的 Wilson 区间是 2.8–12.7%，**只能说点估计达标** | `docs/指标置信区间.md` |
| 测试集只有 100 张 | 每 1 例 ≈ 1 个百分点；能分辨量级差，分辨不了 1–2 个点的差 | 同上 |
| 训练数据全部来自公开集 | v3 的五类权重是自训的，但训练集是公开集（出处待补），**无自采**。不能说「用现场数据训练的」 | `docs/模型卡片.md` 第一节 |
| 两个架构方案被否 | 级联 ROI 精查、双模型 WBF 融合，实测均让漏报变差 | README 6.4 |
