安巡 Agent —— 把摄像头画面变成可执行的整改工单
▶设计特点
▶创新优化
本系统基于自训五类目标检测模型与确定性规则引擎，实现了 PPE 穿戴识别、四态判定、时序聚合、风险分级与工单生成。安全员无需逐帧盯屏，系统把 34.8 秒视频里的 195 条逐帧告警收敛为 13 个事件，输出带处置时限、法规依据与签署位的整改通知单，让巡检真正落得下。

1交付形态创新

  • 告警升级为可签署工单
  • 等级 / 时限 / 依据 / 签署位
  • 195 → 13，降噪 93.33%

2定级有据

  • 等级只看本次确认未佩戴人数
  • 规则引擎给值，模型不拍脑袋
  • 同一输入连跑三次结果一致

3可解释的克制

  • 四态判定 + 三道无效性保护
  • 查不到法条就明说，不编条款号
  • 不预填责任人、地名、验收项

4工程化落地

  • 检测 / 规则 / 编排三层解耦
  • 单模型 + ONNX，工控机可跑
  • 换模型不动业务逻辑
通过安巡 Agent，把厂区巡检的输出由「一条告警」升级为「一张可签署、可追责的整改工单」
