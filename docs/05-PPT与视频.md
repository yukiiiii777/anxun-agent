# 05 · PPT 与视频

> PPT ≤20 页 16:9 ≤50MB；视频 MP4 ≤6 分钟 ≤300MB。
> **PPT 的六个章节就是六项评分维度**，逐条对齐，不要自由发挥。

## 一、PPT 逐页大纲（20 页以内）

### 前 3 页：让人知道你在干什么

| 页 | 内容 | 写法要点 |
|---|---|---|
| **01** | 封面 | 作品名、命题领域、学校、团队、指导老师 |
| **02** | 作品背景与说明 | 团队 3 人分工 + **一句话说清做什么** + 参考来源（官方要求单列此页） |
| **03** | 场景痛点 | 法规刚性 vs 执行虚化，用对比图讲清矛盾 |

> 第 02 页的「参考来源」是官方硬要求，别漏。写清楚引用了哪些法规、标准、数据集。

### 中段 4 页：数据（官方要求 ≥2 个渠道，说明权威性与时效性）

| 页 | 内容 | 写法要点 |
|---|---|---|
| **04** | 数据来源一：公开数据集 | 规模、标注质量、**权威性说明**、出处 |
| **05** | 数据来源二：自采数据 | 采集场景、解决什么分布偏移问题、量级 |
| **06** | 知识库构建 | 法规 / 标准 / 操作 / 经验四层，附条款示例截图 |
| **07** | 数据预处理流程 | 流程图 + **每种数据增强针对哪个现场问题** |

> 第 07 页不要写「我们做了数据增强」。要写「针对车间逆光，Gamma 变换；针对多人遮挡，Random Erasing 10–30%」。

### 分析 3 页：方法（官方点名要思维导图）

| 页 | 内容 | 写法要点 |
|---|---|---|
| **08** | 分析方法选择 | 为什么多 Agent、为什么用风险矩阵定级 |
| **09** | 分析流程 | **思维导图形式**——官方明确点名，别用普通流程图 |
| **10** | 系统架构 | 五 Agent 协同图 + 数据流箭头 |

> 第 09 页用思维导图（XMind / 幕布导出）。这是形式分，画成普通流程图会被扣。

### 技术 4 页：这是全片最难写的四页，队长自己写

| 页 | 内容 | 写法要点 |
|---|---|---|
| **11** | 模型实测指标 | mAP、误报率、漏报率、单帧耗时 + 混淆矩阵 —— **证明不是 PPT 模型** |
| **12** | 为什么放弃火焰检测 | **最有辨识度的一页**。语义判断 vs 存在性判断对比表 |
| **13** | 创新点 + 跨学科视角 | 感知闭环 + 定级有据 + 三层学科融合（官方加分页） |
| **14** | 结果解读 | 实测案例：从告警 → 工单 → 复查的完整时间线 |

> **第 11 页必须有实测数字。** 现在四个数全空，等 C3–C5 任务完成才能填。
> 若时间来不及，如实写「当前版本指标」而不是编数字。

### 后 6 页：价值、局限、演示、收尾

| 页 | 内容 | 写法要点 |
|---|---|---|
| **15** | 价值量化 | 巡检覆盖率、闭环时长、真实合规率三个指标前后对比 |
| **16** | 问题与优化建议 | **主动承认 2–3 个不足**并给优化路径，别装完美 |
| **17** | 风险识别与应对 | 隐私（工人影像）、误报信任、责任边界三类风险 |
| **18** | 应用对话界面 | **真实截图**，不要设计稿 |
| **19** | 提示词示例 + Agent 链接 | 3 组提示词及输出 + **可点击链接**（官方硬要求） |
| **20** | 结尾 | 落地路径与展望，1 页收住 |

## 二、几个关键页怎么写

### 第 11 页：指标页

不要只放一张表。要放：

```
┌─────────────────────────────────────────────┐
│  指标表                                      │
│  mAP@0.5      0.8X    目标 ≥0.85             │
│  误报率       X.X%    目标 ≤10%              │
│  漏报率       X.X%    目标 ≤5%               │
│  单帧耗时     XX ms   目标 ≤50ms             │
├──────────────────┬──────────────────────────┤
│  混淆矩阵（图）    │  PR 曲线（图）            │
├──────────────────┴──────────────────────────┤
│  误差来源分析：远距离小目标 XX%、逆光 XX%…    │
└─────────────────────────────────────────────┘
```

**右下角那块「误差来源分析」是加分项。** 它证明你知道模型在哪里不行，而不是只会报喜。

### 第 12 页：为什么放弃火焰检测

这是全片最有辨识度的一页，做成左右对比表：

| | 火灾/烟雾检测 | PPE 穿戴检测 |
|---|---|---|
| 任务本质 | 语义判断「像不像火」 | **存在性判断**「头上有没有」 |
| 干扰源 | 蒸汽、粉尘反光、红色物料 | 遮挡、光照 |
| 精度天花板 | 换厂区就掉 | 稳定可做高 |
| 演示风险 | 光线一变就翻车 | 录几遍都一致 |

**底部一句话**：

> 在工业场景里，宁可做一个可靠的小任务，也不做一个不可靠的大任务。

### 第 13 页：创新点

两个创新点，各配一句能被记住的话：

- **感知闭环**：让 Agent 有眼睛。「看得见 → 判得准 → 落得下」
- **定级有据**：等级不由大模型拍脑袋。R = L×S 查表 + 法规条款映射

跨学科视角写成一句：**安全工程的风险矩阵 × 计算机视觉的检测能力 × 管理学的 PDCA 闭环。**

### 第 16 页：主动说局限

从 [`03-技术架构.md`](03-技术架构.md) 第九节抄。**至少写 3 条。**

装完美的作品在答辩现场一戳就破；主动说局限的，评委反而觉得你想清楚了。

### 第 19 页：官方硬要求页

这一页缺内容就是零分：

- [ ] **3 组提示词 + 对应输出截图**（真实跑出来的，不是编的）
- [ ] **可点击的 Agent 链接**（自己先点一遍确认能打开）
- [ ] 链接最好同时做成二维码，防现场网络问题

## 三、6 分钟视频

### 3.1 分镜

| 时间 | 段落 | 画面 | 旁白要点 |
|---|---|---|---|
| **0:00** | 黑屏白字（3 秒） | 屏幕中央一行字：「一个安全员，管不了三个车间。」 | 「法规要求每个作业人员正确佩戴劳动防护用品。但现实是——检查的人一走，帽子就摘了。」 |
| **0:20** | 现场照片 + 数据条 | 几张厂区实拍（没戴帽 / 通道堆放），叠加覆盖率与合规率差 | 「不是工人不怕，是没人盯着。安全员一个人管几个车间，覆盖不过来。」 |
| **0:45** | 方案总览 · 架构图 | 五个 Agent 横向链路图，逐个亮起 | 「安巡 Agent 把这条链路交给五个角色协同——规划、看、判、派、查。」 |
| **1:30** | 数据与知识库 | 公开数据集规模 + 自采照片 + 四层知识库 | 「公开数据集保证泛化，自采数据保证落地。法规知识库让每条结论都能追到条款。」 |
| **2:30** | **演示一 · 识别（40s）** | 真实画面 → 检测框实时出现 → 未戴帽者标红 → 置信度显示 | 「画面里三个人，两个戴了，一个没有。系统给出 0.91 的置信度。」 |
| **3:10** | **演示二 · 定级（30s）** | 同一违规在不同区域算出不同等级 | 「同样是没戴帽子，在高处作业平台是 R=16 立即停工的红色风险，在原料库装卸区是 R=3 加强关注的蓝色。」 |
| **3:40** | **演示三 · 闭环（40s）** | 工单自动生成 → 责任人、2 小时时限、可验证动作 → 条款依据弹出 | 「系统不只报警，它派了一个活，给了责任人和时限。」 |
| **4:20** | 技术判断与价值 | 火焰检测对比 + 两个创新点 + 三个量化指标 | 「我们放弃了火焰检测，因为…」（见答辩话术） |
| **5:20** | 风险与展望 | 局限清单 + 落地路径 | 主动说局限，展示清醒度 |

### 3.2 录制要点

1. **演示三段必须连续录屏，不要剪碎** —— 评委要看的是「一次交互里跑通全链路」
2. **别念 PPT，用讲的**
3. **画中画人像**，观感比纯录屏好一档
4. **全程语速平稳**，6 分钟不要赶。官方要求是「不超过」，不是「必须满」
5. **找安静的地方录**，一次录不完就分段录，别边录边改稿

### 3.3 时间不够时怎么砍

砍到 5 分钟以内也能交：

- 砍掉 0:20 的现场照片段（省 15 秒）
- 砍掉 1:30 的数据段，压到 20 秒（省 40 秒）
- 演示三段一秒都不要砍

> 演示是唯一不可替代的部分。

## 四、提交前自查

### 4.1 格式硬性要求

- [ ] PPT ≤ 20 页，16:9，≤ 50 MB
- [ ] 视频 MP4，≤ 6 分钟，≤ 300 MB
- [ ] 压缩包 ≤ 200 MB，**只有一个文件**
- [ ] 命名格式：`命题领域-学校-队长姓名-作品名称`
- [ ] PPT 第 19 页含可点击 Agent 链接（**自己点一遍**）
- [ ] PPT 第 19 页含 ≥3 个提示词示例及输出截图

### 4.2 内容完整性（对照官方六章）

- [ ] 作品背景与说明：有团队分工、有参考来源
- [ ] 数据收集与处理：≥2 个渠道，说明权威性与时效性；有预处理流程图
- [ ] 分析过程：有方法选择依据；**有思维导图**
- [ ] 创新性与独特视角：1–2 个创新点 + 跨学科视角
- [ ] 结果解释与建议：结果价值、2–3 条不足与建议、风险识别与应对
- [ ] 应用结果呈现：对话界面截图 + 提示词 + 链接

### 4.3 技术核查

- [ ] Agent 链接在**非本人设备**上能打开并正常交互
- [ ] 演示用的案例数据已固定，不会因重跑而变
- [ ] 风险定级可复现：同一输入连跑三次，等级一致
- [ ] 法规条款引用能在原文中**逐字查到**
- [ ] 输出中不含任何人脸身份信息（自查一遍截图）
- [ ] 模型指标是自己实测的，不是引用别人的
- [ ] **没有把目标值写成实测值**
