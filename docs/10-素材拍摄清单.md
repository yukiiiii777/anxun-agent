## 一、为什么今晚就要出这份清单

负责 PPT 和视频的人，第一天最该做的**不是排版**，是把素材需求提前扔给要拍摄的人。

原因很简单：PPT 第 11 页要指标、第 18 页要界面截图、第 19 页要链接——这些 11/04–11/05 才产出，现在做只能做空壳。

但**视频里有两段素材，只有明天能拍**：

| 视频段落 | 需要什么 | 只有明天能拍的理由 |
|---|---|---|
| 0:20 现场照片 + 数据条 | 厂区实拍（没戴帽、通道堆放） | 场地和人明天在，之后不一定 |
| 2:30–4:20 演示三段 | **真实的连续人员走动镜头** | 演示的输入源，合成不了 |

补拍的成本极高：要约场地、约人、借安全帽、约晴天。

**所以第一步不是打开 PPT，是写这张表。**

## 二、先分清两种素材

很多人在这里搞混，结果拍回来一堆不能用的东西。

| | **数据集照片** | **视频素材** |
|---|---|---|
| 目的 | 训练模型 | 剪进 6 分钟视频 |
| 数量 | ≥300 张 | 20–30 段 |
| 特点 | 多而杂，追求多样性 | 少而长，追求稳定连续 |
| 格式 | 横竖都行 | **必须横屏 16:9** |
| 谁负责 | 队长（B2/B3） | **你** |
| 时长要求 | 单张 | 每段 ≥10 秒，演示段 ≥60 秒 |

> 拍 300 张照片是队长的活。你要的是**另外 20 段视频**，别混在一起拍。

## 三、视频素材清单（必拍）

### A 组 · 开场空镜（对应 0:20，约 15 秒成品）

| # | 内容 | 要求 | 时长 |
|---|---|---|---|
| A1 | 车间 / 厂区全景 | 固定机位，横屏，尽量带到通道与设备 | 15s |
| A2 | 通道推进（缓慢横移或前进） | 不要手持抖动，能稳则稳 | 10s |
| A3 | 设备特写（管线、机台） | 交代环境，不要求有人 | 10s |
| A4 | 安全帽挂在墙上的空镜 | 有隐喻感，「帽子在那，人没戴」 | 10s |

### B 组 · 痛点镜头（对应 0:00–0:45）

| # | 内容 | 要求 | 时长 |
|---|---|---|---|
| B1 | 人员不戴安全帽走动 | 侧面或背面，走完整一条直线 | 15s |
| B2 | 安全帽拿在手上 | 近景，手部+帽子清楚 | 10s |
| B3 | 多人一起走动（部分戴部分不戴） | 制造「真实场景不是整齐划一」的感觉 | 15s |
| B4 | 消防通道被货物占用 | 全景，能看出「堵住了」 | 10s |

> B 组最好有 2–3 个不同场景的版本，剪辑时挑最好的一条。

### C 组 · 演示输入素材（对应 2:30–4:20，**最重要**）

这一组决定整个视频能不能看。**必须连续、稳定、不中断。**

| # | 内容 | 要求 | 时长 |
|---|---|---|---|
| **C1** | **单人走入画面 → 站定 → 离开** | **固定机位，不变焦不移动；人站定 ≥5 秒** | **≥60s** |
| **C2** | **单人戴帽动作全程** | 从摘下 → 拿在手上 → 戴上，动作慢一点 | **≥60s** |
| **C3** | **两人同框，一人有帽一人无帽** | 都站定 ≥5 秒，用于对比判定 | **≥60s** |
| C4 | 远距离人员走动（>15m） | 演示「无法判定」的小目标保护 | 30s |
| C5 | 逆光位置人员站立 | 演示弱光/逆光场景 | 30s |
| C6 | 多人重叠走过 | 演示遮挡场景 | 30s |

**C1–C3 要点：**

- 机位固定，三脚架或靠墙放稳，**不要手持**
- 人不做夸张动作，正常走进来、站住、走出去
- 站定期间保持 5 秒以上不动（模型要连续 3 帧一致才定论）
- **一段拍砸就重拍，不要凑**——这是整个演示的地基

### D 组 · 数据与知识库配图（对应 1:30）

| # | 内容 | 要求 |
|---|---|---|
| D1 | 安全帽、反光背心、护目镜摆在一起 | 俯拍，干净背景，做「品类」配图 |
| D2 | 标注工具界面截图 | 打开一张已标注的图，截全屏 |
| D3 | 法规 PDF 页面截图 | 有条款号的那一页 |
| D4 | 数据统计表截图 | 类别分布图 |

> D 组是**截图**不是拍摄，但你今晚就要把需求告诉队长：让他标注时顺手截图、下载法规时顺手存 PDF。

### E 组 · 收尾镜头（对应 5:20）

| # | 内容 | 要求 | 时长 |
|---|---|---|---|
| E1 | 人员戴好安全帽正常作业 | 正向收尾，画面干净 | 15s |
| E2 | 车间全景（与 A1 呼应） | 同一机位再拍一次，光线可不同 | 15s |

## 四、拍摄规范（八条，贴在手机备忘录里）

1. **横屏拍摄，16:9**。竖屏素材基本用不了
2. **1080p 及以上**，帧率 30fps 就够
3. **每段 ≥10 秒**，宁长勿短。剪的时候可以砍，短了没法补
4. **固定机位优先**。手持只在 A2 用，且要尽量稳
5. **不加滤镜、不美颜、不开防抖裁切**——裁切会改画面比例，影响检测
6. **每个场景拍 2–3 遍**，现场挑
7. **避开正脸可识别的特写**。要拍人时用侧面、背面，或让同学戴口罩/帽子。后期如有正脸必须打码
8. **原始文件不压缩、不转微信**。用数据线拷，微信会压成 720p

## 六、现场执行（30 分钟拍完）

| 时段 | 动作 | 谁 |
|---|---|---|
| 前 5 分钟 | 架好机位，找好光，试拍 10 秒回放确认 | 你 |
| 5–15 分钟 | 拍 C 组（演示素材）——**趁人最有精神、场地最干净时先拍最难的** | 你 + 1 名同学当演员 |
| 15–25 分钟 | 拍 A、B、E 组 | 你 |
| 25–30 分钟 | 补拍漏项，当场回放检查 | 你 |

**顺序很关键**：先拍 C 组。因为 C 组需要「演员」配合，人一累动作就散；A/B/E 是空镜和环境，最后拍不会掉质量。

## 七、场地受限的降级方案

| 情况 | 降级做法 |
|---|---|
| 进不去真厂区 | 用学校实训车间 / 车库 / 走廊，只要有「工业感」的设备和通道 |
| 借不到安全帽 | 淘宝/五金店买 2 顶，几十块钱，比没有强 |
| 找不到「演员」 | 队友上。拍背面和侧面，不需要演技 |
| 光线太差 | 手机补光灯或借台灯，白平衡后期统一 |
| 完全拍不了 C 组 | ⚠️ **这是最坏情况**：演示改用已有公开数据集的可视化结果 + 本地录屏，PPT 里如实说明素材来源 |

## 八、拍完之后立刻做的一件事

**当晚把 C 组素材跑一遍检测**（哪怕模型还没训好，用 `infer_api.py` 挂个预训练权重）。

目的不是看准不准，是确认三件事：

- [ ] 画面里的安全帽能被检出（类别对得上）
- [ ] 人员框面积是否 ≥8000 px²（不够就得重拍更近）
- [ ] 逆光/远距场景是否大量「无法判定」

**如果 C 组素材不满足检测条件，还有时间在 11/02 补拍。等到 11/06 录屏时才发现，就来不及了。**
